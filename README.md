# Лендинги Siteix — открытые HTML-шаблоны

10 отдельных HTML-страниц для услуг и воронок: шесть отраслевых лендингов плюс четыре страницы под ремонт, поддержку, проверку сайта и партнёрскую программу.

Шаблоны без сборщика: чистый HTML, CSS и немного JavaScript. Можно открыть, заменить тексты, фото и контакты и использовать на своём хостинге.

## Как использовать

1. Скачайте нужную папку или весь репозиторий.
2. Замените название, логотип, телефон, мессенджеры и цены.
3. Подключите форму к своему API: откройте `assets/form-demo.js` и замените `API_ENDPOINT` и `API_TOKEN`. Сейчас там заглушки `https://api.example.com/lead` и `***`.
4. Замените `privacy/index.html` на свою политику обработки персональных данных.
5. Проверьте тексты, ссылки и SEO-метатеги перед публикацией.

Форма отправляет JSON на API и показывает успех/ошибку. Авторизация вынесена в константу с комментарием; не храните реальный токен в публичном репозитории, лучше проксировать запрос через свой backend.
